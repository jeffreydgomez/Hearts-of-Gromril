# Warhammer: The End Times — Credits

This is the central credits document for the HOI4 conversion. It carries forward the EU4 Warhammer Fantasy Universalis credits, except its mod developer/contributor roster, and adds the artwork and sources used by this conversion. Studio and mod-team credits for supplied artwork, models and game assets are retained.

Inherited credits are preserved as source acknowledgements; they do not imply that every asset from the EU4 mod is present here. Asset records also retain superseded portraits so their attribution is not lost.

### Imported artwork, models and interface assets

- **Warhammer Fantasy Universalis source assets:** flags, religious symbols, terrain panels, great-project illustrations, advisor portraits, loading paintings, map textures and unit models. The inherited artist credits above apply wherever the source identifies them; individual file authors remain unknown where the source does not provide a mapping.
- **Nagash alignment revision:** the former Undead alignment emblem is reused for Nagash. Evil-group religious subtypes reuse the existing source religious atlas, including the Nehekharan and Nagash-worship symbols; no new illustration is commissioned or generated. Current symbol provenance.
- **The One Faith:** its existing EU4 Warhammer religion-atlas emblem (frame 30) is reused for the Unaligned subtype. The source artwork is unchanged. Symbol provenance.
- **Anbennar and Elder Scrolls Universalis teams:** the source mod explicitly credits these teams for its unit models. Model source credits and conversion/asset record preserve that collective attribution and per-file provenance.
- **Paradox Interactive / Paradox Development Studio:** installed EU4 cultural advisor/model dependencies and HOI4 interface frames, silhouettes, templates and other retained base-game assets. Advisor provenance lists the specific source files and fallback status.
- **Terrain:** Underway, Great Maze, Caverns, Dwarf Karak, Warren City, Chaos Wastes and urban panels derive from the source mod; the Realms of Chaos panel uses this project’s generated sky. Terrain sources and hashes. The inherited Chaos Wastes artwork credit is John Blanche; no additional individual attribution is inferred from an unnamed file.
- **Landmarks:** source great-project artwork, including the documented Grail-themed fallback. Project/art inventory.
