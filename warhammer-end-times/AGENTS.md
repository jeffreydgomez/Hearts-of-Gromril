# Warhammer: The End Times — Project Instructions

Read and follow `Dev Stuff/AGENTS.md` before working anywhere in this mod.

Keep all development notes and tooling under the existing `Dev Stuff` folder.
Do not recreate `Dev Notes` or introduce another parallel development folder.

Only create, edit, move, or delete files inside this `warhammer-end-times`
folder. The EU4 Warhammer mod and the vanilla HOI4 installation are read-only
references; never modify either reference folder.

Maintain the root `CREDITS.md` whenever adding or replacing credited assets.
Preserve creator/source links and documented stand-ins in `Dev Stuff`; see
`Dev Stuff/conversion/build_credits.py` for reproducible credits generation.
